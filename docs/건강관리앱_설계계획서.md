# 종합 건강관리 앱 설계계획서
**(가칭) 헬씨플랜 — 식단·운동·생활습관 통합 관리 개인 맞춤형 앱**

---

## 1. 프로젝트 개요

### 1.1 목표
식단, 운동, 생활습관을 하나의 앱에서 종합 관리하고, 사용자의 목표(체중 유지·증량·감량)에 맞춘 개인 맞춤형 플랜을 제공한다. 가족 구성원과 식단을 자연스럽게 공유하되, 민감한 정보는 보호하여 서로 부담 없이 사용할 수 있도록 한다.

### 1.2 핵심 가치
- **통합**: 식단 + 운동 + 생활습관을 한 곳에서
- **맞춤**: 목표별(유지/증량/감량) 자동 칼로리·영양 목표 산출
- **배려**: 가족 공유 시 "보여줄 것만 보여주는" 프라이버시 설계
- **실용**: 야외(GPS 지도 트래킹)와 실내(홈트) 운동 모두 지원

---

## 2. 개발 방식 추천

### 결론: **PWA(프로그레시브 웹앱)로 시작 → 필요시 Capacitor로 앱 패키징**

| 방식 | 장점 | 단점 |
|------|------|------|
| **PWA (추천)** | 웹 기술(HTML/JS/React)로 개발, 홈 화면 설치 가능, iOS/안드로이드/PC 모두 지원, 배포·수정 즉시 반영, GPS·카메라 사용 가능 | 백그라운드 GPS 트래킹 제한(화면 켜진 상태에선 정상 동작), 앱스토어 미등록 |
| 네이티브 앱 | 백그라운드 트래킹·센서 완전 지원 | iOS/안드로이드 별도 개발, 심사·배포 부담 큼 |
| Capacitor 하이브리드 | PWA 코드 그대로 앱스토어 등록 가능, 백그라운드 GPS 플러그인 사용 가능 | 초기 설정 학습 필요 |

**추천 이유**: 선생님께서 이미 웹앱 개발 경험이 있으시고(문화나들이, 영어 대화 지도 등), 지도·GPS·카메라는 PWA에서도 충분히 동작합니다. 러닝 중 화면을 끈 상태의 백그라운드 기록이 꼭 필요해지면 그때 Capacitor로 감싸면 코드 재작성 없이 해결됩니다.

## 3. 핵심 기능 설계

### 3.1 식단 관리 모듈
- **일 단위**: 아침/점심/저녁/간식 기록, 사진 첨부, 음식 검색(식약처 식품영양성분 DB 활용), 칼로리·탄수화물·단백질·지방 자동 계산
- **주 단위**: 주간 식단표(계획 vs 실제 비교), 장보기 목록 자동 생성
- **월 단위**: 월간 캘린더 뷰, 영양 균형 리포트, 목표 달성률 그래프
- **목표별 식단 추천**:
  - 감량: 목표 칼로리 적자(-300~500kcal), 고단백 식단 제안
  - 유지: TDEE 기준 유지 칼로리
  - 증량: 칼로리 잉여(+300~500kcal), 단백질 체중 1kg당 1.6~2.2g 가이드
- **AI 맞춤 추천(선택)**: Claude API 연동 — 냉장고 재료 입력 → 목표에 맞는 식단 제안

### 3.2 운동 모듈
**야외 운동 (지도 트래킹)**
- 걷기/러닝/자전거 모드
- GPS 실시간 경로 지도 표시(카카오맵 또는 Leaflet + OpenStreetMap)
- 거리, 시간, 페이스, 소모 칼로리 기록
- 운동 후 경로 지도 저장·히스토리 조회

**실내 운동 (홈트레이닝)**
- 운동 라이브러리: 부위별(전신/상체/하체/코어) 맨몸·기구 운동
- 루틴 빌더: 세트·횟수·휴식시간 설정, 인터벌 타이머(음성/진동 알림)
- 목표별 추천 루틴: 감량(유산소+서킷), 증량(근력 위주), 유지(균형)
- 스트레칭·요가 가이드

### 3.3 생활습관 모듈
- 체중·체지방 기록 및 추이 그래프
- 물 섭취 체크(목표 대비)
- 수면 시간 기록
- 걸음 수(모바일 센서 연동)
- 습관 체크리스트(예: 계단 이용, 야식 금지)

### 3.4 개인 맞춤화
- **온보딩 설문**: 성별, 나이, 키, 체중, 활동량, 목표(유지/증량/감량), 알레르기·기피 음식
- **자동 계산**: BMR(기초대사량) → TDEE(활동대사량) → 목표 칼로리·영양소 배분
- **주간 피드백**: 목표 대비 실적 요약, 다음 주 플랜 자동 조정

### 3.5 가족 공유 (배려 설계 ★)
"서로 불편하지 않게"가 핵심 원칙:
- **공유되는 것(기본)**: 주간 식단표, 장보기 목록, "오늘 저녁 뭐 먹을까" 투표
- **비공개(기본)**: 체중, 체지방, 칼로리 섭취량, 운동 기록 — 항목별로 본인이 공개 여부 선택
- **응원 기능**: 구체적 수치 없이 "오늘 목표 달성!" 배지만 공유 가능
- **가족 식단 조율**: 구성원별 목표가 달라도(아빠 감량, 아이 성장) 같은 메뉴에서 1인분 양·구성만 다르게 제안

---

## 4. 화면 구성 (주요 7개)

1. **홈 대시보드**: 오늘의 칼로리 잔여량, 운동 요약, 물·걸음 수 위젯
2. **식단**: 일/주/월 탭 전환, 기록·계획·리포트
3. **운동**: 야외(지도) / 실내(루틴) 탭
4. **트래킹 지도**: 실시간 경로, 시작/일시정지/종료
5. **리포트**: 체중 추이, 영양 균형, 운동량 그래프
6. **가족**: 공유 식단표, 투표, 응원
7. **설정**: 목표 변경, 공개 범위, 알림

---

## 5. 기술 스택

| 구분 | 선택 | 비고 |
|------|------|------|
| 프론트엔드 | React + Tailwind CSS | PWA(서비스워커, 매니페스트) |
| 지도 | 카카오맵 API 또는 Leaflet | GPS는 브라우저 Geolocation API |
| 차트 | Recharts | 체중·영양 그래프 |
| 데이터 저장 | 1단계: IndexedDB(로컬) → 2단계: Supabase 또는 Firebase | 가족 공유는 2단계부터 필요 |
| 음식 DB | 식약처 식품영양성분 공공데이터 API | 무료 |
| AI 추천 | Claude API(선택) | 식단·루틴 자동 생성 |
| 배포 | Vercel 또는 Netlify | 무료 시작 가능 |

## 6. 데이터 모델 (핵심 테이블)

- **users**: 프로필, 목표, 신체정보, TDEE
- **meals**: 날짜, 끼니, 음식 목록, 영양소 합계, 사진
- **meal_plans**: 주간/월간 계획 식단
- **workouts**: 유형(야외/실내), 경로(GeoJSON), 거리, 시간, 칼로리
- **routines**: 실내 운동 루틴(운동 목록, 세트, 횟수)
- **habits**: 물, 수면, 걸음, 습관 체크
- **family_groups / shares**: 그룹 구성원, 항목별 공개 설정, 투표

## 7. 개발 단계 (로드맵)

**1단계 — MVP (개인용, 4~6주)**
- 온보딩 + TDEE 계산
- 일 단위 식단 기록 + 영양 계산
- 실내 운동 루틴 + 타이머
- 체중·물·걸음 기록, 홈 대시보드
- 로컬 저장(IndexedDB), PWA 설치

**2단계 — 트래킹 확장 (2~3주)**
- GPS 지도 트래킹(걷기/러닝/자전거)
- 주/월 단위 식단표, 리포트 그래프

**3단계 — 가족 공유 (3~4주)**
- 회원가입·로그인(Supabase)
- 가족 그룹, 공유 식단표, 투표, 프라이버시 설정

**4단계 — 고도화**
- Claude AI 식단·루틴 추천
- Capacitor 패키징(백그라운드 트래킹 필요 시)

---

## 8. 고려사항

- **건강 정보 주의**: 앱은 일반 가이드 제공용이며 의료 조언이 아님을 명시(면책 문구)
- **프라이버시**: 체중 등 민감정보는 서버 저장 시 본인 계정만 접근, 공유는 옵트인
- **배터리**: GPS 트래킹 시 위치 갱신 주기 조절(3~5초)로 소모 최소화
- **오프라인**: 산길 등 통신 불가 지역에서도 기록되도록 로컬 우선 저장 후 동기화
